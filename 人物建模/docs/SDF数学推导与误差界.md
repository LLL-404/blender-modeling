## 1. `smin` 的闭式、梯度、Hessian

### 1.1 闭式

Inigo Quilez 多项式 smin：

```
h   = max(k − |a−b|, 0) / k
d   = min(a,b) − h²k/4
```

在过渡带 `|a−b|<k` 内把 `min` 展开（`δ=a−b`，分 `δ≥0` / `δ≤0` 两支，结果相同）：

```
d = (a+b)/2 − k/4 − (a−b)²/(4k)
```

脚本用 2000 组随机 `a,b` × 3 个 `k` 验证，两边最大差 **6.939e−18**（浮点级）。
**意义**：外面是 `min`，里面是一个二次多项式 —— 可以直接求梯度与 Hessian，不用碰绝对值。

### 1.2 一阶：Eikonal 条件被破坏

```
∇d = (∇a+∇b)/2 − (a−b)(∇a−∇b)/(2k)
```

在等距面 `a=b`：

```
∇d = (∇a+∇b)/2
|∇d| = √((1+cosθ)/2) = |cos(θ/2)| ,   θ = ∠(∇a, ∇b)
```

真 SDF 必须满足 Eikonal 方程 `|∇d|=1`。`smin` 只在两法线同向时满足；**相向时 `|∇d|→0`，法线退化**。

本项目算例（两圆半径 20mm、圆心 ±18mm、相交 2mm）：颈部 `y=√(R²−C²)=8.7178mm`，

```
∇a = (C, y)/R ,  ∇b = (−C, y)/R
|∇d| = y/R = 8.7178/20 = 0.4359
```

中心差分实测同为 **0.4359**。

**工程后果**：`SDFGridOffset(Δ)` 平移的是「距离值」，真实几何位移是 `Δ/|∇d|`。
所以「两场各 `Offset(−k/4)` → UNION → `Offset(+k/4)`」这条近似 smin 的路，
在颈部实际膨胀 `(k/4)/0.4359 = 2.294·(k/4)`。`k=4mm` 时：

| 算法 | 颈部半径 |
|---|---|
| 硬并集 `k=0` | 8.7178 mm |
| 精确 smin `k=4mm`（解析 `r=√((R+k/4)²−C²)`） | **10.8167 mm** |
| 一阶线性 `(k/4)/|∇d|` | 11.0120 mm（**高估 9.3%**） |

**结论：路 B 不能当等价替代，只能当一阶近似，且偏差随 `k` 增大。**

### 1.3 二阶：颈部为什么变尖/变圆

在 `a=b` 处：

```
H_d = (H_a + H_b)/2 − (∇a−∇b)(∇a−∇b)ᵀ/(2k)
```

第二项是**秩 1 负半定**，作用在两法线差的方向上。它给出两件事：
- 沿该方向曲率被压大（这是 `k` 越小颈部越尖的解析原因）；
- `1/k` 说明 `k→0` 时曲率发散 —— 硬并集的尖角在离散网格上不可表示。

## 2. 数值实验：零水平集的曲率与面积

形状关于原点星形，故可沿每条射线用二分法解 `d(r,θ)=0`，得到 `r(θ)`（2048 个角度、64 次二分）。极坐标曲率：

```
κ = (r² + 2r'² − r·r'') / (r² + r'²)^{3/2} ,   ρ = 1/|κ|
A = ½ ∮ r² dθ
```

| `k` (mm) | 面积 (mm²) | 面积增幅 | 颈部 `r` (mm) | 颈部 `ρ` (mm) |
|---:|---:|---:|---:|---:|
| 0（硬并集） | 2466.29 | — | 8.7178 | **0.0129**（离散残差，理论 0） |
| 0.5 | 2466.40 | 0.004% | 9.0009 | 0.140 |
| 1 | 2466.71 | 0.017% | 9.2770 | 0.292 |
| 2 | 2467.90 | 0.065% | 9.8107 | 0.630 |
| 4 | 2472.46 | 0.250% | 10.8167 | 1.452 |
| 6 | 2479.74 | 0.545% | 11.7580 | 2.489 |
| 8 | 2489.62 | 0.946% | 12.6491 | 3.774 |

二次拟合 `ρ(k) = 0.02763k² + 0.24839k + 0.014` mm。

**两条设计结论**：

1. **面积代价很小**：`k=8mm` 也只胀 0.95%。smin 主要是「局部磨圆」，不是「整体吹大」。
2. **融合与保细节互斥**：要让融合带的曲率半径达到耳轮 2.8mm，反解 `k≈6.51mm`；
   但按 §1.2，`k` 同时带来整体膨胀 `k/4≈1.63mm`，耳廓会被鼓大。
   换句话说：**想让接缝圆得自然，就得牺牲耳轮的细边**。这不是调参能绕开的，是 smin 自身的尺度关系。

`k=0` 那行的 `ρ=0.0129mm` 只是离散残差（理论尖点 `ρ=0`），
**不能**拿它当「要保住的特征尺寸」去反解体素 —— 第一版脚本这么算，得出 `h≤0.120mm`，
属于口径错误，已改成用设计融合带 `k=2mm` 的 `ρ=0.630mm`。

## 3. 网格化误差界与体素反解

`GridToMesh`（marching cubes）在体素边上做线性插值，两个误差上界：

| 界 | 公式 | 含义 |
|---|---|---|
| 采样界（保守） | `e ≤ √3·h/2` | 体素对角线的一半 |
| 插值界 | `e ≈ h²/(8ρ)` | 曲面在一条边上的弦高，`ρ` 取设计融合带 0.630mm |

容差取耳轮 2.8mm 的 5% = **0.14mm**：

```
采样界  → h ≤ 2·0.14/√3 = 0.1617 mm
插值界  → h ≤ √(8·0.630·0.14) = 0.8397 mm
取小    → h ≤ 0.1617 mm   （采样界主导）
```

**上一轮试点写的 `Voxel Size = 0.5mm` 不够**：`e = √3·0.5/2 = 0.433mm`，
是耳轮 2.8mm 的 **15.5%**，远超 5% 容差。

| `h` (mm) | 采样误差 (mm) | 插值误差 (mm) | 满网格 | 窄带估算 |
|---:|---:|---:|---:|---:|
| 0.10 | 0.0866 | 0.0020 | 576 MB | 11.4 MB |
| **0.162** | **0.1400** | **0.0052** | **130 MB** | **4.38 MB** |
| 0.25 | 0.2165 | 0.0124 | 36.9 MB | 1.84 MB |
| 0.50 | 0.4330 | 0.0496 | 4.6 MB | 0.46 MB |

窄带估算按「表面积 ≈5000mm²，表面体素 × 带宽 6 层 × 4B」。
**手册查证后修正**：《网格转为SDF栅格》「条带宽度…只有该范围内的体素才存储有意义的带符号距离值」、
《重构网格修改器》「体素：使用 OpenVDB …生成流形网格」→ 稀疏窄带是**官方确认**，不再是推断。
但手册不给内存数值，`4.38MB` 仍是估算，**峰值内存必须在试点里量**。

## 4. `Iterations` 不是拍的：Laplacian 就是热扩散

显式拉普拉斯迭代 `d ← d + λ·(Σ邻域 − 2m·d)`（m 为维数）在傅里叶域的响应：

```
G(q) = 1 − 4λ sin²(q/2) ≈ exp(−λ q² n)     （n 次迭代，小 q）
```

对应热方程 `∂d/∂t = DΔd`，`D = λ/h²`，等效方差 `σ² = 2Dtn = 2λ n h²`：

```
扩散长度  L = σ ∝ h√n
```

稳定条件（CFL）：`λ ≤ 1/4`（2D 五点）、`λ ≤ 1/6`（3D 七点）。

**2D 数值验证**：两方形硬并集的尖角，`λ=0.24`，量零水平集在角部的 95 分位位移，
拟合 `log(位移) ~ log(n)` 得斜率 **0.4549**（理论 0.5，差 9%，来自有限网格与角部位移饱和）。
数量级与 √n 标度一致，足以否定「迭代 2~4 轮就能融合」。

**换算成本**：要在 `h=0.162mm` 上得到 `k=2mm` 的融合带，

```
n = (k/h)² = (2 / 0.162)² ≈ 153 轮
```

上一轮文档写的 `Iterations 2~4` 只对应 `L = h√n ≈ 0.23~0.32mm`，差两个数量级。

**注意**：`SDFGridLaplacian` / `SDFGridMean` 的迭代语义与上式直接对应；
**手册查证后更正**（Blender 5.2 LTS 中文版《SDF圆角》专页）：Fillet 不是纯 Laplacian，
它是「仅作用于负主曲率（凹角）区域、保持整体体积不变」的**定向圆角**，
官方用途写明「在布尔运算后消除硬性过渡」；「迭代越高，圆角半径越大」。
所以语义已明确，但手册**不给迭代→半径的定量式**，`L≈h√n` 不能直接套。
**Iterations 仍须实测标定**：扫描 n，量颈部曲率半径，拟合实际标度律再反推 n。
