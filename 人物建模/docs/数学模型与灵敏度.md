# 人物建模的数学模型与参数灵敏度

> 2026-11-05。目的：把「这个模型到底由什么数学对象构成、哪些参数真的能推动结果」写清楚，
> 再据此开工。结论全部来自 `scripts/sensitivity.py` 的实跑数值，不是文献综述。

## 0. 一句话

当前管线是 **参数化截面放样 + Catmull-Clark 极限曲面 + 高斯位移场叠加 + 沿射线投影贴合**。
可解的是「参数 → 几何量」，不可解的是「几何量 → 像不像」。实测 12 个参数全部可测，
但其中 2 个响应极弱、2 个存在跨部件耦合 —— 这决定了 phase 3 该先动哪里。

## 1. 表示法（逐层写清）

### 1.1 头骨：超椭圆截面族

每个 z 环是一个**前后半轴不同**的超椭圆：

```
|x / rx|^p + |(y − cy) / ry|^p = 1        ry = ryf (y < cy), ryb (y ≥ cy)
```

`HEAD_RAW` 是 17 行 `(z, rx, ryf, ryb, cy, p)` 表。沿 z 用 Catmull-Rom 重采样到
`CAGE_STEP = 0.018m`（约 13 环），每环 `CAGE_SEG = 24` 段，环间直纹桥接成控制笼。

`sz(z)` 把「旧头绝对 z」映射到当前头骨：
```
sz(z) = a + (z − a)·s + t,  a = 1.3836
s = clamp((H / r) / L, 0.6, 1.6),  L = 1.618 − 1.3836 = 0.2344
t = H − (a + L·s)
```
`H` = 身高，`r` = 头身比。当前 `H=1.68, r=6.5` → `s=1.102652, t=0.037938`。
`look.py` 里有完全相同的 `sz()` 副本（不能互相 import），改这里必须同步。

### 1.2 细分与收缩补偿

Catmull-Clark 极限曲面 `S = lim_{n→∞} Cⁿ(M₀)`，除奇异点外 C²。极限曲面比控制笼**向内收**，
且收多少随轴不同（超椭圆 x/y 半轴曲率不同）：

| 轴 | 未补偿 SUBD/BASE 跨度比 | 补偿系数 | 补偿后残差 |
|---|---|---|---|
| x | 0.98596 | `CAGE_GROW_X = 1/0.98596 = 1.01424` | 0.001% |
| y | 0.97735 | `CAGE_GROW_Y = 1/0.97735 = 1.02318` | 0.001% |
| z | 1.00001 | 不动 | — |

用一个笼统的 1.0232 会把头宽多放大 0.9%（约 1.6mm），而 `head_w_over_len` 是硬判据。
这两个数由 `scripts/probe_cage.py` 实测给出，不是拍脑袋。

### 1.3 位移场：控制笼级 + 顶点级

控制笼级位移只在明确的解剖 z 环上做（`cage_sculpt`），角度用 smoothstep 带 `_band(t, lo, hi, soft)`：

```
Δx,Δy,Δz = Σ_part  f_part(z 环, 方位角 da)
```

顶点级位移是**各向异性高斯的和**（`sculpt`）：

```
Δy(x,z) = Σ_i a_i · exp(−(x/σx_i)²) · exp(−((z−z_i)/σz_i)²)
Δz, Δx 同理（下巴、颧骨）
```

各部件（眼窝/眉弓/鼻/唇/下巴/颧骨）返回**增量序列**，门面按固定顺序逐条 `dy += e`。
这不是代码风格问题：浮点加法不满足结合律，让部件返回「总和」再累加会改变顶点 hash。
`phase 1` 就是靠这个办法把 592 行 `head.py` 拆成 8 模块而 hash 逐位不变。

### 1.4 五官贴合

眼/眉/嘴是先在 XZ 平面生成多边形（fan / band），再沿 +Y 射线投到颅骨 BVH：

```
y(v) = y_hit(x_v, z_v) − d_i,   d_i = 0.0012 ~ 0.0038m
```

所以它们**没有厚度**，侧面只是贴纸。这是「结构缺位」的数学根源，也是 phase 3 要改的对象。

### 1.5 比例归一化

```
head_unit = 2 · max(rx of head_rows())      # 名义头骨宽，当前 0.213914m
```

横向尺寸 = 系数 × `head_unit`；z 位置 = `sz()`；只有 y 向雕刻深度保留 mm。
例外（BOSS 2026-11-05 定）：`EYE_X = 0.0405m` 与耳高 `45.82mm` 保持绝对，不随头缩放。

## 2. 量尺的解析式与雅可比

| 量尺 | 定义 | 雅可比 |
|---|---|---|
| 内眼角/眼宽 `R` | `R = (2x − e)/e = 2x/e − 1` | `∂R/∂x = 2/e = 47.7 m⁻¹`；`∂R/∂e = −2x/e² = −46.3 m⁻¹` |
| 眼裂高宽比 | `(h↑ + h↓)/e` | `∂/∂h↑ = 1/e` |
| 嘴宽/脸宽 | `2h / W_head` | `∂/∂h = 2/W_head = 8.90 m⁻¹` |
| 鼻尖前伸 | `y_fore − y_tip`（额面窗口 − 鼻尖窗口最前点） | 对 `a_tip` 近似线性，但受额面窗口耦合 |
| 头宽/头长 | `W_head / (z_top − z_chin)` | `∂/∂W = 1/L` |

**解析 vs 实测**（±10% 参数，相对变化 `S = (g(1.1p)−g(0.9p))/g(p)`）：

| 参数 | 解析预测 | 实测 | 一致 |
|---|---|---|---|
| `eye_w_r` → `R` | `−0.4x/(eR) = −0.415` | **−0.419** | ✓ |
| `eye_x_mm` → `R` | `+0.4x/(eR) = +0.415` | **+0.415** | ✓ |
| `mouth_w_r` → 嘴宽比 | `+0.200`（线性） | **+0.200** | ✓ |
| `ear_h_r` → 耳高 | `+0.200`（线性） | **+0.196** | ✓ |
| `tip_fwd_mm` → 鼻尖前伸 | `+0.200` | **+0.273** | ✗ 超线性 |
| `bridge_h_mm` → 鼻尖前伸 | `0`（鼻梁不在鼻尖窗口） | **−0.017** | ✗ 反向耦合 |

两处不一致都有明确原因，不是测量错：

- **鼻尖超线性**：`a_tip` 的高斯 σz = 0.0085m 会溢出到额面窗口 `sz(1.520)~sz(1.570)`，
  额面基准也被往前推了一点，于是「前伸 = 额面 − 鼻尖」被放大。这个 gauge 不是纯净的鼻尖量。
- **鼻梁反向**：`bridge_h` 让额面窗口前移，而鼻尖窗口基本不变，表观前伸反而**变小**。
  说明 `nose_protrusion_mm` 同时受鼻梁和鼻尖控制，不能用它单独反解 `tip_fwd`。

## 3. 实测灵敏度（`scripts/sensitivity.py`，12 参数 × 16 量尺，30.9s）

| 参数 | 主要响应量尺 | S | 判读 |
|---|---|---|---|
| `eye.eye_w_r` | `R` −0.419、`eye_width` +0.200、`eye_aspect` −0.177 | 高 | 最划算的杠杆 |
| `eye.eye_x_mm` | `R` +0.415 | 高 | 与眼宽几乎对称，但内移会让脸显窄 |
| `eye.eye_h_up_r` | `eye_aspect` +0.113 | 中 | — |
| `lips.mouth_w_r` | `mouth_over_face` +0.200 | 高 | 线性 |
| `nose.tip_fwd_mm` | `nose_protrusion` +0.273、`head_depth` +0.005 | 高 | 超线性，见 §2 |
| `nose.bridge_h_mm` | `nose_protrusion` −0.017、`cheek_front_y` −0.009 | 低 | 反向耦合 |
| `ear.ear_h_r` | `ear_height` +0.196 | 高 | 线性 |
| `ear.rim_mm` | `head_width` +0.005、`ear_x_span` +0.029 | 低但跨部件 | **动耳必须复测头宽**（代码注释里的经验结论有数学依据） |
| `jaw.jaw_inset_mm` | `jaw_width_r` −0.002 | **极弱** | 控制笼位移被细分平均掉 |
| `jaw.chin_fwd_mm` | `chin_front_y` −0.015、`head_depth` +0.004 | 中低 | — |
| `cheek.cheek_out_mm` | `cheek_front_y` −0.004、`nose_protrusion` +0.002 | **极弱** | — |
| `cheek.cheek_fwd_mm` | `cheek_front_y` −0.006 | 低 | 需要专属 x 带量尺才测得到 |

结论：**不要优先改 `jaw_inset` / `cheek_out`**。±10% 只动 0.2~0.4%，投入产出比最差。
优先改眼宽、嘴宽、耳高、鼻尖。

### 一次有价值的误判

第一次扫描报 `eye_h_up_r` 和 `cheek_fwd_mm` 为 **NO-GAUGE**（±10% 推不动任何量尺）。
按合同规则 3 它们本该被当成「假参数」删掉。实际原因是**量尺缺失**：

| 补的量尺 | 之后 |
|---|---|
| `eye_aspect` = sclera 的 z 跨度 / 单眼全宽 | `eye_h_up_r` → +0.113，OK |
| 颧骨专属 `cheek_front_y`：只在 `0.060 ≤ |x| ≤ 0.095` 的 x 带里取最前 y | `cheek_fwd_mm` → −0.006，OK |

原先取「整个颧骨 z 环的 min(y)」会被鼻尖主导，根本测不到颧骨。
**规则`：NO-GAUGE 先怀疑量尺，再怀疑参数。** 补完 12/12 全部可测。

## 4. 病态性：哪些参数从图里根本解不出来

### 4.1 单视图的投影歧义

参考图是 3/4 视角 + 头部倾斜。设未知旋转 `R`、平移 `t`、正交尺度 `s`，
从 2D 关键点反解 3D 参数是：

```
min ‖Π(s·R·M(p) + t) − I‖
```

对 `(p, R, t)` 有无穷多组解。正面眼距、脸宽、鼻深在 3/4 投影里都被透视压缩，
拿这张图反解会得到「在这个角度凑对、转正就错」的形状。
**几何真值只能来自设计 spec / 多视图；这张图只提供风格、配色、发型类型和信息密度。**

### 4.2 剪影 IoU 只能解宽度

参考 vs 模型：IoU **0.5351**，横向缩放+平移的仿射上界 **0.5644**。
两者只差 0.03 → 把头发改宽改窄最多再拿 0.03，剩下 0.44 是形状本身。
刘海长度、卡片层数、发梢形状几乎不改外轮廓，用剪影去解它们是病态反问题
（多组参数给出同一个 IoU）。所以 `fit_silhouette.py` 只解宽度，其余交给视觉闸门与人眼。

### 4.3 高斯位移场的 a / σ 耦合

`a·exp(−(x/σ)²)` 在单张正面渲染里，「宽而浅」与「窄而深」能给出很接近的明暗边界。
要把 `a` 和 `σ` 分开，必须有几何量测（顶点坐标）或多视角。
当前 `nose_protrusion_mm` 只能量峰值，`tip_sigma_r` 没有任何量尺 —— 这是合同里 TODO 的几条。

### 5.1 phase 3 第一次尝试：失败，已回退（2026-11-05）

| 项 | 内容 |
|---|---|
| 做法 | 在原有 5 层平面 fan（sclera/iris/pupil/高光/睫毛）之上，**叠加**扁椭球眼球 + 上下眼睑 Solidify 壳 |
| 白模证据 | `out/clay_face_eye_closeup.png`：一堆互相穿插的白色薄片，左右不对称，上缘有锯齿 |
| 彩渲证据 | 回退前 `out/m3_face_front.png`：眼周出现碎玻璃状白色锯齿，虹膜被碎片切割 |
| 处置 | `lib/head_parts/eye.py` 的 `ENABLE_VOLUME = False`，函数保留但停用；Head hash 精确回到 `a41051ab7e803221` |

**数学根因（这才是研究要的结论）**：所有贴片共享同一个映射

```
y(x,z) = y_hit(x,z) − d_i,   d_i ∈ [0.0006, 0.0038] m
```

各层深度只差 0.6~3.8mm。再叠一个有厚度的实体，多个**近共面曲面**在同一 `(x,z)` 上争深度 →
z-fighting；描边壳（Solidify 外扩 6.92mm）再把这些碎片勾成黑边。
问题不在参数、不在厚度，而在**表示法**：沿 +Y 射线的投影贴合本身就不允许 y 方向体积。

**正确方向：不能「叠」，要「换」**

```
S = { (x,y,z) | ((x−cx)/R)² + ((y−cy)/R)² + ((z−cz)/R)² = 1 }
```

用球面当眼白，去掉平面 sclera fan；iris/pupil/高光投到**球面的 BVH**（不是颅骨 BVH）；
眼睑用球面参数域 `(θ, φ)` 的带，沿法线给厚度。这样所有曲面共享一个参数化，
不存在近共面竞争。这一步是下一轮的活，不在原方向加第三个变体。

**同一轮的实质进展**：`scripts/render_clay.py` 已建立 —— 中性灰、无描边、无 bloom、
无 alpha 的四张白模图（front/side/34/眼部近景）。这次失败正是靠白模先发现的；
彩渲只是二次确认。判几何用彩渲的缺陷到此补上。

### 5.2 phase 3 第二次尝试：换表示法，成功

严格球面与眼窝的 5.2mm 高斯凹陷不兼容（球冠边缘会退到颅骨后面被吃掉），
改用**一张共享曲面** `S(x,z) = y_hit(x,z) − LIFT − BULGE·exp(−((x−cx)/w)² − ((z−cz)/h)²)`：

| 层 | y 取值 | 说明 |
|---|---|---|
| 眼白实体 | `S − 0.0002`（前）/ `S + BACK_DEPTH`（后） | 封闭透镜，同心环精确采样 S，不再用平面 fan |
| 虹膜 / 瞳孔 / 高光 | `S − 0.0012 / 0.0018 / 0.0024` | 深度差是显式常量，不是各层各自 conform 抢出来的 |
| 上/下眼睑 | `S − 0.0020`（前）/ `S + LID_THICK`（后） | 四边封口的实体壳，整体位于眼白之前 |
| 睫毛 / 下眼缘 | `S − 0.0028` | 线稿层同样用 S 定位 |

**中途一次修正**：第一版眼白前表面用单个三角 fan 近似 S，BULGE=1.2mm 的凸冠
在 21mm 半径上会产生约 1mm 的插值误差，与虹膜 δ 同量级 → 虹膜局部穿到眼白后面，
白模渲成扇形斑块。改成三环精确采样 S + 把 δ 拉到 1~2.8mm 后消失。
这是「曲面离散误差 > 层间深度」的问题，不是 z-fighting，别再往深度上瞎调。

**验收**（`scripts/head_baseline.py`）：

| 项 | 结果 |
|---|---|
| Head hash | `c91c9426de253783`（两次一致），顶点 7812 → 8518 |
| 颅骨 hash | `d11a4f8fccec092c` —— **与 phase 2 逐位一致**，实体化没动颅骨 |
| A2 五条 | 5 PASS / 0 FAIL，眼距 0.93054、嘴宽 0.1200 保持 |
| `check.py` | 73 PASS / 12 FAIL / 0 HOLE —— **与改动前完全相同**，没引入新失败 |
| `lid_thickness` 几何实测 | **1.200 / 1.200 mm**（合同要求 ≥0.8mm） |
| 白模侧视 `clay_face_side.png` | 眼睛有凸出体积与眼睑转折，不再是零厚度贴纸 |
| 彩渲 `m3_face_front.png` | 虹膜/瞳孔完整，上一版的碎玻璃锯齿消失 |

**遗留**：`face_detail.py` 的睫毛/眉丝线稿仍 conform 到**颅骨** BVH，
与新的 S 曲面错位，眼周与嘴角有少量细碎白点。下一轮把线稿也改成用 S 定位，
或按部位给独立的贴合曲面。不属本次实体化的失败。

## 6. 边界

- 这套数学保证「参数 → 几何」确定、可复现、可测量；**不保证「几何 → 好看」**。
- 可微渲染拟合 `min ‖R(M(p)) − I‖`（建模方法研究 §2 路线 F）仍然是缺的一环：
  当前只有数值雅可比，没有把雅可比接进优化器。接之前不要声称「AI 会从图拟合模型」。
- 换参考图后 `visual_gate` 基线从脸密度 0.1325 掉到 0.0746，门槛自动降 44%。
  判据的判别力必须重验（`--selftest`），否则「变绿」只是标准松了。
