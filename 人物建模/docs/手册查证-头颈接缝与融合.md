## 2. 逐页查证（摘录官方原话）

| 手册页（路径） | 官方原话（摘录） | 对头颈接缝的含义 |
|---|---|---|
| `modeling/geometry_nodes/volume/operations/sdf_grid_fillet.html` **SDF圆角** | 「仅作用于具有**负主曲率（凹角）**的区域，同时**保持整体体积不变**」「适用于交叠形状的柔和过渡处理，或**在布尔运算后消除硬性过渡**」「迭代：数值越高，形成的**圆角半径越大**」 | **官方对症解法**。脖子与下颌相交正是凹角；且保体积，不会把下巴鼓大 |
| `.../sdf_grid_boolean.html` **SDF栅格布尔** | 「并集：通过计算每个体素处的最小距离，将两个栅格合并」「效果类似于网格布尔运算，**但能呈现平滑连续的视觉效果**」 | 官方承认普通布尔是「硬」的，SDF 并集是「平滑连续」的 —— 正是我们缺的那一层 |
| `modeling/meshes/editing/edge/bridge_edge_loops.html` **桥接循环边** | 「删除所有选中的面，然后在**两个或多个选中的边环之间创建新面**」；「切割次数」「**混合曲面**：沿贝塞尔样条创建新的边循环点，**同时考虑相邻曲面的法向**」「平滑度」「轮廓系数」 | **我上一轮 B 方案的现成实现**，而且比我说的更强：混合曲面能给出 C¹ 连续，轮廓系数能调中间段收/胀 |
| `modeling/modifiers/deform/shrinkwrap.html` **缩裹修改器** | 「移动物体的每个顶点到所给网格的最近的表面」「**顶点组**控制每个顶点是否移动以及移动多少」 | 可让颈柱顶贴合头骨，但**只解决贴合，不解决 49.5mm 的截面差** |
| `sculpt_paint/sculpting/tool_settings/remesh.html` **重构网格（体素重构）** | 「执行此操作将**丢失与原始网格关联的所有网格物体数据层**」「已知局限：**忽略从修改器、形态键、绑定等生成的几何结构**」 | **官方确认**「融合会毁 UV/权重/形态键」；我们 `body.build()` 之后才在 `m5_rig` 按空间重建权重，与此一致 |
| `modeling/modifiers/generate/remesh.html` **重构网格修改器** | 「体素：**使用 OpenVDB** 从当前的几何体生成一个新的流形网格，同时尝试保留网格的原始体积」 | 我 SDF 调研里「窄带稀疏是推断」→ **手册确认是 OpenVDB 稀疏场** |
| `modeling/geometry_nodes/mesh/operations/mesh_to_sdf_grid.html` **网格转为SDF栅格** | 「条带宽度：网格表面周围**活动体素带**的宽度…**只有该范围内的体素才存储有意义的带符号距离值**」「体素大小越小，越精确但内存越多」 | 确认 `Band Width` 的语义；也确认我把 0.162mm 体素当精度瓶颈是对的 |
| `.../grid_to_mesh.html` **栅格转为网格** | 「通过提取指定阈值的等值面…**类似于 Marching Cubes**」「对于 SDF 栅格，**阈值 0.0 通常对应于表面**」「适应性 0.0 禁用自适应」 | 确认 `sdf_math.py` 的误差界前提与试点里 `Threshold=0` 的写法 |
| `.../sdf_grid_laplacian.html` **SDF栅格拉普拉斯** | 「拉普拉斯流…将细微细节扩散至相邻体素」「迭代：数值越高平滑度越高，**但可能导致表面轻微收缩**」 | 与 `sdf_math.py` 推导的扩散标度 `L≈h√n` 一致；手册额外提醒「收缩」，和我说的「抹平细节」同向 |
| `.../sdf_grid_offset.html` **SDF栅格偏移** | 「正向扩张、负向收缩，**保持场内正确的符号距离值**」「控制形状间的**混合边缘**」 | 见 §5 澄清：与我的 2.294× 结论不矛盾 |
| `modeling/modifiers/generate/booleans.html` **布尔修改器** | 「**只有流形网格才能保证得到正确的结果**」「准确解算器完全支持重叠几何体」 | 提醒：直接对 Head+Body 做布尔有前提，别把「插进去 9.17mm 的重叠」当成安全输入 |
| `modeling/modifiers/deform/corrective_smooth.html` **矫正平滑** | 「在骨架修改器之后…减少关节附近扭曲」「**钉固边界**」「缩放补偿体积损失」 | 与项目 R2/R3 权重法线 FAIL 相关，但属绑定侧，本轮不展开 |

## 3. 对照上一轮的实测数字

`out/neck_joint.json`：颈柱顶 z=1430.88mm、头底 z=1421.72mm、`head_body_gap=−9.17mm`（插进去，没有缝）；
z=1424mm 处头骨宽 26.2mm、颈柱宽 75.7mm（**Δw=+49.5mm**）。

| 手册做法 | 能不能消掉这 49.5mm | 代价 |
|---|---|---|
| 桥接循环边（混合曲面） | **能**：在两个边环之间生成过渡面，法向连续 | 不动拓扑/UV/权重，纯几何编辑；需要两边环顶点数可控 |
| 缩裹修改器 | **不能**：只把顶点投到表面，截面差还在 | 零成本，可做辅助 |
| SDF 并集 + SDF圆角 | **能**：凹角圆化、保体积、平滑连续 | 栅格转网格会丢 UV/权重/描边分层（手册「丢失所有数据层」） |
| 直接布尔并集 | 能合并但**仍是硬过渡**，且要求流形 | 手册明确风险 |
| 现有 `voxel_remesh(5mm)` | 只融 Body 内部，Head 不参与 | 手册：「忽略绑定、形态键」 |

## 4. 手册修正了前几轮的四处判断（已同步改文档）

| 文件 | 原来写的 | 手册查证后 |
|---|---|---|
| `docs/SDF融合体调研.md` | 「`SDFGridFillet` **实现未公开**，Iterations 语义不确定，必须实测标定」 | 手册有专页：只作用凹角、保体积、迭代↑=圆角半径↑，**不是拉普拉斯平滑**。语义已明确；只有「迭代→半径」的定量式手册没给，仍需标定 |
| `docs/SDF融合体调研.md` / `docs/SDF数学推导与误差界.md` | 「`Band Width` **暗示**稀疏窄带存储，是推断，峰值内存需实测」 | 手册两处确认：活动体素带 + **OpenVDB**。推断升级为确认；内存**数值**仍需实测 |
| `docs/SDF数学推导与误差界.md` | 「体素重网格会毁拓扑/UV/权重」（我们自己的经验） | 官方原话更狠：「**丢失所有网格物体数据层**」「忽略修改器、形态键、绑定」—— 结论不变，依据升级 |
| `docs/头颈接缝诊断.md` | 修法 B「参数化过渡环（用 slices.json 驱动控制环）」 | 手册里 **桥接循环边** 就是现成实现，且带混合曲面/轮廓系数；B 升级为「手册现成操作 + 切片数据给环的位置」 |

**没有作废的**：`sdf_math.py` 的 `L≈h√n`、误差上界、2.294× 放大、17 控制层 9.30mm / 天花板 8.23mm —— 手册给的是定性描述，不给这些数，两者互补。

## 5. 一处看似矛盾，说清

| 手册 | 我的数学推导 |
|---|---|
| 《SDF栅格偏移》：「保持场内**正确的符号距离值**」「均匀作用」 | 《SDF数学推导与误差界》§1.2：用 `Offset(−k/4)→UNION→Offset(+k/4)` 近似 smin 时，几何位移放大 **2.294×** |

不矛盾：手册说的是 Offset 节点对**真 SDF** 精确；我算的是 **smin 破坏 Eikonal 条件之后**（`|∇d|=0.4359`）再拿 Offset 去近似融合，位移被放大。
结论仍是：**路 B 只能当一阶近似，不能当 smin 的等价替代**；而且手册说 Offset 是「均匀作用、控制混合边缘」，本来就不是局部融合算子。

## 6. 手册给的可执行路线（仍未动代码）

| 优先 | 做法 | 依据 | 验收 |
|---|---|---|---|
| 1 | **桥接循环边 + 混合曲面插值**，在颈柱顶边环与下颌底边环之间生成 3~5 段过渡面；环的位置由 `out/slices.json` 给 | 《桥接循环边》《网格转为SDF栅格》不需要 | 同高度 `Δw/Δd ≤ 5mm`、白模侧视无硬切线、UV/权重/描边不变 |
| 2 | 局部 SDF：Head + Neck 各转 SDF 栅格 → 并集 → **SDF圆角**（只作用凹角、保体积）→ 栅格转网格（阈值 0） | 《SDF栅格布尔》《SDF圆角》《栅格转为网格》 | 体素 ≤0.162mm、峰值内存实测、UV/权重按手册警告重传 |
| 3 | 缩裹修改器（顶点组限定颈柱顶） | 《缩裹修改器》 | 只能辅助，单独用不解决 49.5mm |
| 不做 | 直接布尔并集 / 整头体素重构 | 《布尔修改器》流形警告、《重构网格》已知局限 | — |

**判断不变**：现在 `flow` 0/6 过闸，先修 body 的手与 face 的三渲二；接缝修法 1 是唯一不动拓扑的，要做就做这条，但要 BOSS 点头。
