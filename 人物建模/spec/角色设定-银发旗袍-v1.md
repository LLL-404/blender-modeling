## 〇、原文照录（用户 brief，一字未改）

### 一、角色基础建模设定

- 定位：三渲二二次元可动角色（适配 MMD / Blender / Unity 卡通渲染管线）
- 风格：赛璐璐硬边轮廓 + 简化PBR材质，偏向《崩坏3》《绝区零》级三渲二精度
- 头身比：6.5 头身（二次元少女标准比例，肢体修长，胯部略宽于肩部）
- 基准身高：168 cm（含鞋跟）
- 核心识别元素：银白低马尾+蓝挑染 / 深蓝波点蝶形发饰 / 渐变运动墨镜 / 银白祥云纹挂脖旗袍 / 侧边交叉绑带 / 黑色雪纺飘袖

### 二、形体基准参数（建模参考）

| 部位 | 比例基准 | 建模注意 |
| --- | --- | --- |
| 头部 | 占全身 1/6.5 | 脸型偏尖鹅蛋脸，下巴收窄，颧骨平缓 |
| 肩宽 | 1.8 头宽 | 溜肩线条，肩峰圆润无棱角 |
| 腰围 | 1.2 头宽 | 腰线内收明显，旗袍贴身无余量 |
| 胯宽 | 1.6 头宽 | 胯部略宽于肩，大腿饱满 |
| 腿长 | 3.8 头长 | 小腿略长于大腿，脚踝纤细 |

- 布线要求：面部保持 4 边面循环线，眼窝、嘴角、下颌线预留变形环；肢体关节处加 3 条以上循环边，支持骨骼绑定弯曲。

### 三、服装结构拆解（建模分层）

**1. 旗袍主体（内层核心）**

- 领型：立领挂脖式，前中一颗水滴形金属盘扣，领口贴合颈部
- 衣身：无袖修身剪裁，整体呈直筒微收腰，正面完整覆盖
- 纹样：表面祥云暗纹，为低对比度浮雕纹理，建模可用法线贴图实现，无需实体凸起
- 开衩：双侧超高开衩，开衩起点在胯骨上方，开衩边缘有细棕色包边
- 侧边结构：腰胯部为交叉绑带设计，共 3 组横向绑带+金色圆形铆钉固定，绑带宽度 1.5 cm，实体建模凸起

**2. 外搭飘袖（独立部件，可拆分）**

- 结构：上臂处金色手环固定，向下垂落的宽袖雪纺面料
- 形态：自然垂坠褶皱，袖口不规则毛边，整体半透明
- 绑定：根部跟随大臂骨骼，袖身可加 2~3 段辅助骨骼做布料动力学

**3. 发饰与配饰**

- 蝶形发饰：左右对称两片，深蓝色底+均匀蓝色波点，根部有银色星形底座，实体建模
- 墨镜：大框运动款，镜框黑色亮面，镜片蓝紫渐变半透明，架在头顶发顶处
- 领部饰件：立领中心盘扣下挂水滴形灰色吊坠，金属包边

### 四、三渲二材质规范

| 材质区域 | 基础属性 | 三渲二表现要点 |
| --- | --- | --- |
| 皮肤 | 偏冷瓷白，低粗糙度 | 硬边阴影，仅在颧骨、鼻尖加柔和高光；禁用真实次表面散射，用渐变贴图模拟 |
| 头发 | 银白主色+发梢蓝挑染 | 两层高光：主高光锐利条状，副高光柔和；发片边缘加 1px 深色轮廓线 |
| 旗袍丝绸 | 银灰色缎面，低粗糙度 | 各向异性高光，横向拉丝纹理；阴影硬边，褶皱处明暗对比强烈 |
| 雪纺飘袖 | 纯黑，半透明 | 透明度 30%，双面渲染；褶皱阴影柔和，不接受投影 |
| 金属饰件 | 亮金色/亮银色 | 高反射，硬边高光；边缘加黑色描边强化卡通感 |
| 墨镜镜片 | 蓝紫渐变 | 半透明+环境反射，反射强度 20%；镜片边缘加亮边 |

### 五、三渲二渲染规范

1. 轮廓线：全角色统一 1.2px 黑色外描边，关节褶皱处不额外加粗；服装内部结构用 0.8px 深色内描边
2. 光照：主光+辅光+轮廓光三光源，阴影硬边无渐变；禁用柔和环境光遮蔽
3. 面数控制：身体主体 8000~12000 面，头发 4000~6000 面，服装 5000~8000 面，适合实时渲染
4. UV 规范：面部、头发、服装分 3 张 UV 集，纹理分辨率 2048×2048；对称部位可镜像复用

## 一、量参换算（brief → 机器表，推导过程全列）

口径沿用 `reference.json` 的既定约定：**头身比与头长一律用骨相头顶**（不含发饰/墨镜），头长 = 身高 ÷ 头身比。

| 量 | 推导 | v2 值 | 落表键 |
| --- | --- | --- | --- |
| 头长 | 1.68 / 6.5 | **0.2585 m** | `head_len.target`（tol 0.006） |
| 头宽 | 0.872 × 0.2585（头形风格沿用 v1） | 0.2254 m | 由 `head_w_over_len` 推出 |
| 可见颈长 | 0.36 × 0.2585（修长系颈长系数沿用） | 0.093 m | `neck_visible.target` |
| 肩宽/头宽 | brief §二 直给 | **1.8** | `shoulder_over_headw.target` |
| 腰宽/胯宽 | 1.2 / 1.6 | **0.75** | `waist_over_hip.target` |
| 腰宽/肩宽 | 1.2 / 1.8 | **0.667** | `waist_over_shoulder.target` |
| 腿长/身高 | 3.8 / 6.5 = 0.585（腿长口径） | — | 见下 |
| 裆高/身高 | 1 − 0.585（表键实测口径 = CROTCH_Z/身高） | **0.415** | `leg_ratio.target`（warn 级） |

> ⚠ `profile.appearance.leg_length_ratio` 旋钮**没有**跟着改：它只缩腿管几何（body.py 以膝为铰点），与实测口径的 `cfg.CROTCH_Z` 常量解耦——翻它是假动作。腿目标已落 `reference.json` 的 `leg_ratio`，实现要等 rebuild 时改 `cfg.CROTCH_Z` 并重校躯干/服装连锁。

`head_w_over_len`（0.872）、`head_len_over_depth`（1.322）、`head_body_gap`（0, −12mm~+2mm）三条 brief 未涉及、属头形/接缝不变式，**沿用 v1 值**。

### 待作者拍板的三个出入（不改原文，只挂账）

1. **肩 vs 胯**：§一散文说「胯部略宽于肩」，§二表格却是 肩 1.8 头宽 > 胯 1.6 头宽。本表按**表格值**落（表格更量化），散文按风格意图理解（溜肩使视觉肩点下移内收，胯观感反宽）。
2. **身高含鞋跟**：168cm 含鞋跟，鞋跟高度未给。骨相身高暂按 1.68 全高参与推导（`_meta` 已注明口径），rebuild 时按实际鞋跟高度回校。
3. **腿长极长**：3.8 头长 ≈ 身高的 58.5%（v1 为 53%），属时尚插画级修长，是 brief 明确意图，照登；`leg_ratio` 维持 warn 级（只记录不拦），rebuild 后看剪影再决定是否收紧。

## 三、验收分级口径（视觉门人工复核阶梯）

自动闸门只量画面信息密度（见 `spec/visual_gate.json` 的 `_boundary`）。**像不像**按下列阶梯人眼复核，自下而上逐层放行：

1. **比例**：头身 6.5、肩 1.8 头宽、腰 1.2、胯 1.6、腿 3.8 头长 —— 对应 `spec/reference.json` must/warn 键；
2. **色块**：银白发+蓝挑染 / 银灰旗袍+白祥云 / 黑飘袖 / 深蓝波点蝶饰 / 金饰件，位置与占比对齐参考图；
3. **发型轮廓语言**：低马尾走向、刘海分缝、鬓发长度、蝶饰位置 —— 剪影级对齐；
4. **服装形制**：挂脖领、开衩位、绑带组数（3 组）、飘袖垂坠形态 —— 形制正确优先于纹样精度。

每层通过才看下一层；下层不过时上层再像也不算过。

## 四、本设定的消费关系

- `spec/visual_gate.json` → `reference_image` 已指向本设定参考图；基线必须由该图 `--calibrate` 重算（闸门纪律：禁止照当前模型数值反调阈值）。
- `spec/reference.json` → 共享键（头身比/头长/肩腰胯腿）已换 v2 值；v1 专属键（裙摆锥度/发帽厚度等）摘 target 留档于快照。
- `params/profile.json` → 外观旋钮已换 v2 值（身高/头身比/腿长比/发色）；形制落差表（§二）为 rebuild 输入。
