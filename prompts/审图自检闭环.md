# 提示词模板：Blender 建模审图自检闭环

> 来源：`Blender体检/README.md`「AI 自检闭环协议」。**规范口径以来源为准**，本文件是可直接粘贴的会话模板；改口径先改来源，再同步本模板。

---

对 `<模型绝对路径>.blend` 执行建模质检闭环：

1. **渲染**：`bash "D:/G/github/实用工具/Blender建模/Blender体检/check.sh" "<模型>.blend"`（默认 16 环绕+顶视+拼版；EEVEE headless 失败换 `--engine workbench`）。跑完核对 17+1 张图 + manifest 齐全。
2. **读图**：读 `Blender体检/out/<模型名>/sheet.png` 总览，可疑处再读对应 `view_*.png` 细看。
3. **问题单**：按视角列结构化问题——每条含「视角 / 严重度 / 描述 / 能否脚本修」。典型检查项：轮廓走形、比例失调、部件穿插、法线翻黑面、贴图错位/丢失、材质异常、构图裁切。
4. **修复**：只有「可脚本修」的（缩放、位移、旋转、法线重算、修改器、命名）才写 bpy 修复脚本执行；造型/拓扑/贴图绘制类只提意见不动手。**写回前确认没有前台 Blender 开着该文件**。
5. **复渲复检**：重跑 check.sh 对照上一轮，最多 3 轮。
6. **报告**：输出 `out/<模型名>/report_round<k>.md`，最终通过或把剩余问题列入手工清单。

安全纪律：渲染永远只读（headless、核对源文件 mtime 不变）；落盘白名单（工具目录 ∪ 模型所在目录）；产物只落工具 out/。
