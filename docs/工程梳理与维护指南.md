## 三、AI 建模标准 SOP（下次开工照此走）

1. **读索引**：`.agent/tools/blender/index.md`（入口清单；方法论唯一口径在 skills/…/SKILL.md 与 Blender体检/README.md，改口径去那边）。
2. **选通道**：建模 QA → `bash check.sh <model.blend>` + 读 sheet.png 开问题单（复渲 ≤3 轮）；程序化角色 → 先 DESIGN.md（比例表+配色+分阶段量化验收），再几何→骨架→材质→细节。
3. **验收**：人物建模改动后 `python 人物建模/scripts/build.py check`（六探针）；一切渲染走 headless、核对源文件 mtime 不变。
4. **归档**：定稿模型 `python 人物建模/scripts/build.py archive`（时间戳副本落散件归档）。
5. **收尾**：临时件只留 out/（gitignored）；提交在 ZCode 会话外做（Mimosa 门）。
