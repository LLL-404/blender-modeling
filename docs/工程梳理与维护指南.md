## 三、AI 建模标准 SOP（下次开工照此走）

1. **读索引**：`.agent/tools/blender/index.md`（入口清单；方法论唯一口径在 skills/…/SKILL.md 与 Blender体检/README.md，改口径去那边）。
2. **选通道**：建模 QA → `bash check.sh <model.blend>` + 读 sheet.png 开问题单（复渲 ≤3 轮）；程序化角色 → 先 DESIGN.md（比例表+配色+分阶段量化验收），再几何→骨架→材质→细节。
3. **验收**：人物建模改动后 `python 人物建模/scripts/build.py check`（六探针）+ `python 人物建模/scripts/measure.py`（外观比例，must 级 0 FAIL）；一切渲染走 headless、核对源文件 mtime 不变。
4. **归档**：定稿模型 `python 人物建模/scripts/build.py archive`（时间戳副本落散件归档）。
5. **收尾**：临时件只留 out/（gitignored）；提交在 ZCode 会话外做（Mimosa 门）。

## 四、给 AI Agent 的上下文防污染规则

1. 临时件只落 `out/`（已 gitignore），不进对话上下文；产物可由脚本再生，**不把渲染 PNG/base64 复制进上下文**。
2. 删除只认作者点名、PowerShell 直删不走回收站；不建仓根散件；新目录先在 README 登记。
3. prompts/ 与协议口径**单一来源**：模板只是会话速用件，改口径必须回 Blender体检/README.md 与 SKILL.md（源头），同步模板。
4. 提交永远在会话外；`.zcode/`、`.mimosa/` 是运行态，勿入库勿手编。
5. 跨仓契约清单：stardust 6 处绝对路径（游戏仓 .blend/产物/export）、blender-rig SRC=reroute-godot、CodeArts junction（.codeartsdoer/skills/blender-procedural-character → 本仓 skills/）、游戏仓 AGENTS.md:12 以绝对路径调用本仓脚本。**这些路径一个都不要"顺手规范化"。**
