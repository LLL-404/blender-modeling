# D 阶段：发型与服装细节（刘海 / 后发束 / 翻领 / 卷边 / 裙褶）

2026-11-01 实测数字，全部来自 headless `blender -b --python` 几何探针 + 像素统计。
把这一页当"改造型细节时先看什么"的清单用。

## 1. 分组件的分组判据：用「部件包围盒」，不要用顶点级排序间隙

刘海 7 缕等距 → 要改 3 组（中 3 齐、左右各 2 外撇），组间留 1~2mm **真空几何缝**。

**踩过的坑**：把全部刘海顶点按 x 排序、找 >1mm 的断开，得到 **28 段**——单缕
tube 的环在 x 方向只有几个离散值，一缕内部就有 >1mm 空隙，全是假阳性。
用包围盒判据后得到正确的 3 组。

```python
boxes = [(min(c.x for c in cs), max(c.x for c in cs)) for 每一缕]
boxes.sort()
groups = [[boxes[0]]]; gaps = []
for b in boxes[1:]:
    gap = b[0] - groups[-1][-1][1]
    if gap >= 0.0008:            # >=0.8mm 视为组间真缝（目标 1~2mm）
        gaps.append(gap); groups.append([b])
    else:
        groups[-1].append(b)
```
验收：`len(groups)==3 and len(gaps)==2 and all(0.001<=g<=0.002)`。

**缝宽是包围盒口径，不是"中心距 − 全宽"**：外撇组的末端外扩（×1.22/1.26）会把
包围盒撑得很宽（单缕 35mm 宽），中心距算法会给出不同的数。实测第一版缝
6.3mm → 把外撇组向内收 5mm → 1.0mm（贴下界、浮点会判 FAIL）→ 再外移 0.5mm
取 **1.5mm** 才稳。

**副作用**：缝是真空的，正面渲染里额头覆盖率会掉。实测 96.5% → **85.2%**，
仍过 ≥70% 阈值。要预留这个掉幅。

## 2. 纵向发束的沟壑：侧面机位量不到，必须加背面正对机位

后发束是**沿 x 并排、沿 z 延伸**的纵向条。侧视相机沿 x 看，7 条会互相遮挡，
图上只剩最外一条——用它做"后发区域横向采样亮度标准差"，改前 22.44、改完反而
**降到 19.51**，指标根本没在量沟壑。

在 `m4_hair.py` 加背面机位（该文件属可改范围）：

```python
"back": shots.camera("c6", (0, 2.2, 1.45), (0, 0, 1.40), ortho_scale=0.42),
# 循环里描边宽度要按 ortho 分别换算
_set_outline(0.42 if name == "back" else 0.32, 780)
```

**基线必须重测**：改完几何再补机位，就没有"改前"的图了。做法是临时把参数改回
旧值、用新机位渲一次拿基线（旧 2.32），再改回新值渲（7.60 = **3.27×**）。

## 3. 沟壑深度由 thick 封顶，不是 width

截面是椭圆 (width, thick)，y 方向半径只有 thick。两管中心距 d、半宽 w：

```
groove ≈ thick · (1 − √(1 − (d/(2w))²))
```

实测：w=20mm / d=34mm / thick=9mm → 2.8mm；w=18mm → **5.5mm**。
**想把谷挖深，优先压 width 或加大 d，单纯加 width 会把谷填平。**
后脑宽 208mm、7 缕 → d 上限约 34mm（7×34=204）。

配套：`y` 不能往里收。后发片后缘 y≈0.090~0.104，发束中段要压到 0.098~0.106
才包得住它。另验"不露头皮"：发帽 z_max / |x|max 必须都大于 HEAD 表。

## 4. 「峰谷差」不能用全局 max − min

百褶裙 rx=226 / ry=180，全局 max−min 报 **75.9mm**——那量的是椭圆的各向异性
（+x 方向 226 vs +y 方向 180），不是褶。

正确做法两种，都要**同角度邻域**比较：
- 如果环点数能整除褶数：按每 `n/pleats` 个点分组，逐组 max−min 再取平均。
- 否则：按 `atan2(y−cy, x)` 排序后做滑动平均去趋势，取 detrended 的峰谷差。

## 5. 环采样密度要 ≥ 每褶 6 点

22 褶 × `RING_SEG=48` = **2.18 点/褶**，峰谷完全混叠，怎么量都测不出褶形。
改 `SKIRT_SEG = pleats * 6 = 132`（或 176 = 8/褶）。裙子是独立 loft 对象，
不必迁就全局 `cfg.RING_SEG`。

改完 `assert_skirt_clearance` 的采样也会变（`_front_y` 更密）。

## 6. 褶相位与二次谐波

角度约定同 `superellipse_ring`：0°=+x、90°=+y（后）、**270°/−90°=−y（前中）**。

- `cos(pleats·a)` 在 a=270° 处是 `cos(33π) = −1` → **中线是谷**。
- 加 π 相位：`cos(pleats·a + π)` 在 270° 处 `cos(34π)=+1` → **中线是峰**；
  背面 90° 处也同时是峰，左右两侧是谷。
- 叠加 `+ 0.25·amp·cos(2θ)`：θ=0 处 f''=−2（尖）、θ=π 处 f''=0（**平**）→「峰硬谷圆」。
  峰 1.25amp、谷 −0.75amp，峰谷差仍是 2·amp。

实测 z=0.65 环：peak +16.2 / trough −9.7 / diff **25.9mm**，中线 delta 0.0（是峰）。

## 7. 开弧的递增方向别穿过前中

做衬衫翻领时，三圈改成开弧、前中留缺口。第一版 `A0=250, A1=650`（递增），
弧会**经过 270°（正前）**，前中照样有 12 个顶点、探针判"闭合"。
正确是 `A0=290, A1=610`（从右前递增、绕过 90° 正后、到左前 250°）。

另外：`meshkit.loft` 的桥接是 `j2=(j+1)%seg`，**永远首尾闭合**。用它铺开弧
会把缺口两侧硬连成一张横跨的布——顶点仍为空、面却闭合，探针照样报"开口"，
是典型的**假达标**。开弧要按「角度 × 行」手搓四边形（`k` 只到 `seg-2`），
再交给 Solidify 的 use_rim 缝边，边界边数仍为 0。

V 深口径：`后领顶 − 前领顶`。用"前侧所有点的最低 z"会量到领根（恒定 1.300），
把 24mm 报成 38mm；只看 |x|≤30mm 的 V 缺口附近才准（实测 20.1mm）。

## 8. 卷边造型：变径三点 > 等径箍

等径短筒在几何上只是一圈加粗环。改成沿袖轴三点变径
`[(47.0),(49.0),(46.0)]`（外凸再内收）才有折返轮廓。
**半径量级不能放大**：它和袖口间隙（[7,10]mm）共享同一个袖筒半径，
改卷边半径会连带把间隙改掉。验收：凸出仍在 [2,4]mm、边界边数仍 0。

## 9. 像素 ROI 的两类背景/分母陷阱

**(a) 分母不能用 `fg_mask`。** 矩形 ROI 把背景和两侧部件都算进前景：
额头 ROI 用 fg 当分母，覆盖率报 **4.0%**（分母 24104 vs 实际 1791）。
额头区前景只可能是头发或皮肤 → 分母用 `hair + skin`，覆盖率 96.5%。

**(b) 四角取中位会被附属部件污染。** 背面机位左右下角是肩膀皮肤
`(185,165,180)` / `(249,226,210)`，中位背景落到皮肤色上，暗背景 `(53,60,75)`
反而被判成前景——334k 像素里选中 290k，指标全废。
改取**四角中亮度最低的那一角**当背景。

**(c) 不要把「不是皮肤」再加亮度阈值。** 天使环把额头一带的头发打成紫白
`(217,203,240)`、亮度 209，`lum<180` 会把它整片漏掉（覆盖率 53%）。
头发判据就用 `fg & ~skin`。

**(d) toon 三阶色会把沟壑压平。** 阴影档是平色，沟壑 3mm→5.5mm 在亮度上
几乎看不出来。跨版本比较要同一套光照；几何判据（峰顶 y − 谷中点 y）才是主证据，
像素标准差只作辅证。

## 10. 探针专用的 `solid=False` 开关

`solidify` 后内外两层 z 只差约 1mm，按 z 窗口取"裙摆最下环"必然混层
（实测 seg 176 → 264、per_pleat 8 → 12）。
给 `_skirt()/ _sleeve()` 加 `solid=True` 默认参数，探针传 `False` 取干净单环；
默认值必须与正式入口的调用完全一致。

## 11. 同一个文件被并行改写时的处置

改到一半发现自己的常量被改（`COLLAR_A0` 290/610 → 279/621、`SKIRT_SEG`
132 → 176、`_skirt` 多了 `solid` 参数），说明同文件有并行写入者。

- **不要回退**对方改动——那通常是改进（本轮对方修掉了 loft 首尾闭合的假开口）。
- 在对方版本上**复测全部指标**，并在总结里显式写出"文件非我一人所改"。
- 复跑三次确认数值稳定（本轮 D3 1.3434 三次一致、D5 25.9 三次一致），
  排除"数值漂移"是随机性还是别人改动。
