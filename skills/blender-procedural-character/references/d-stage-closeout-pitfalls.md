# 收口阶段的三类「假达标」与接管半成品的操作顺序

适用场景：一个阶段已有人改了一半（或已中止会话遗留的残留实现），你需要
**核验现状 → 补完缺失 → 出数字**，而不是从头重做。

---

## 一、三类假达标（都在实测里真的发生过）

### 1. 放样「永远首尾闭合」→ 顶点空、面闭合的假开口

`meshkit.loft` 的桥接写死 `j2 = (j+1) % seg`，**开弧传进去也会被硬连回起点**。
结果是：缺口两侧确实没有顶点（`|x| < 6mm` 计数 = 0，探针判「开口 OK」），
但有一条横跨缺口的四边形面 —— 渲染上是闭合的。

**识别**：探针只数顶点时必然漏掉。要补一条「面判据」：取缺口角度带内的面，
若存在面的顶点跨到缺口另一侧，即为假开口。

**修法**：放弃 `loft`，按「角度 × 截面行」手搓四边形：

```python
verts = []
for row in rows:            # rows 是若干条开弧点列，长度相同
    verts.extend(row)
faces = []
for k in range(seg - 1):    # 关键：只到 seg-2，不连回起点
    for i in range(len(rows) - 1):
        a = i * seg + k
        b = (i + 1) * seg + k
        faces.append((a, a + 1, b + 1, b))
ob = mesh_from(verts, faces, name="collar")
recalc_normals(ob)          # 必须先定向，Solidify 依赖法线方向
solidify(ob, 0.004)         # use_rim 默认开，会把两条缺口边缝上 → 边界边仍 0
```

### 2. Solidify 前后是两套半径口径（凸出/间隙类判据必踩）

同一条「卷边凸出 3.2mm」可以是真的 3.2mm，也可以是 1.65mm：

- 袖筒**环层**（solidify 之前）末端半径 = 47.00mm —— 这是参数表里的数；
- 袖筒**solidify 之后**的外表面 = **48.34mm**（实测，同比 +1~2mm）；
- 卷边外表面 = 49.99mm。

按环层算：49.99 − 47.00 = **3.2mm**（落在验收带 [2,4] 内，判 PASS）。
按可见表面算：49.99 − 48.34 = **1.65mm**（带宽下限都不到）。

**规则**：
- 「凸出/间隙/留白」这类**可见量**，基准一律取 `solidify` 之后的外表面；
- 探针里同时打印两套口径（`旧环层口径=+4.6mm / visible=+3.3mm`），
  否则跨轮比较会把「换了基准」当成「造型变好了」；
- 实测 solidify 的偏移量，不要按 thickness/2 推：同一套代码在环中心法线处
  实行 +1.0mm，在**环间斜面**处只有 +0.6~0.7mm（法线带轴向分量）。

### 3. 基线本身度量错了对象 → 判据失效，不是退化

「减薄后沟壑变差」是假的：改前半宽 28 / 间距 26 时，相邻发束重叠 30mm，
**交叠处隆起成峰**，横向亮度差分 9.99 量的是那些峰；减薄后峰变少，
差分降到 7.62，被判「0.76×，未达 1.3×」。

判据要能回答「它量的还是我要的那个东西吗」：
- 若基线来自一个**已知有缺陷的形态**（重叠峰 / 假开口 / 串权），
  那它不能当改进基线，只能当对照；
- 主线判据换几何量（峰谷深、可见凸出、V 深），像素量降为旁证并写明失效原因；
- **不要**为了让判据通过而把 baseline 从 9.99 改成 2.32 —— 那是改判据不是修模型。

## 二、探针分段必须对准几何环位置

`tube` 只在**控制点处**生成环。一个三点卷边（t = −10 / −4 / 0 mm）在
t ∈ [−9,−6] 这段**没有任何顶点**，探针量到的是斜面棱上的偏移：

- 取斜段：内缘报 +1.90mm（判 FAIL）
- 对准环位 t ∈ [−11,−8]：内缘报 +3.06mm（判 OK）

**规则**：分段边界必须写死在特征位置上（`(−0.011,−0.008)` / `(−0.005,−0.003)` /
`(−0.001,0.001)`），并在注释里写明「环间是斜面，法线倾斜导致径向增量不足」。
用连续区间去切一个只有离散环的管，量到的是插值误差，不是造型。

同类：`solidify` 的内外层在 z 上错开约 1mm，按 z 窗口取环会混层
（实测 132×2 = 264 个点被当成一个环，每褶 6 点变 12 点、差里掺进椭圆各向异性，
报出 32.2mm 假峰谷差）。给建模函数加 `solid=False` 开关，探针取未 solidify 的
干净单环（约定同 `_sleeve(solid=False)`）。

## 三、接管半成品：先核验、再补、别推翻

被中止会话遗留的实现通常**已写好 80%**，但带一个致命缺陷。实测三种：

| 遗留物 | 已对的部分 | 致命缺陷 |
|---|---|---|
| `_collar()` 开弧三环 | 角度、z 落差、半径梯度都对 | 用 `loft` → 假开口 |
| `_cuff_ring()` 三点变径 | 造型语义（外凸再内收）对 | 基准按 47mm 环层，可见凸出只有 1.65mm |
| `_skirt()` 谐波 + 相位 | 相位 +π、二次谐波 0.25、SEG 132 都对 | 探针口径混层，读数 32.2mm 假值 |

**顺序**：
1. **先跑探针拿基线**（约 5 分钟），别先改代码 —— 否则不知道遗留了什么；
2. 对每一项判「已达标 / 未做 / 做了但未达标」，**只修未达标项**；
3. 修的时候保留遗留实现的语义（角度、相位、梯度），只替换有缺陷的那一层；
4. 每改一项立刻复测，改前后各出一组数。

## 四、文件被并发重写时的落盘手法

现象：`edit` / `write` 反复返回「file has been modified since it was last read」，
`stat` 显示 mtime 每 1~2 分钟跳一次，内容看起来没实质变化（幂等重写）。

**不要**反复重试编辑器 —— 每次都会失败，而且会覆盖掉别人刚写的内容。

**做法**：
1. 先用 `stat` 连观察 3 次（间隔 4 秒），确认文件是否稳定；
2. 改用**内容锚点的幂等补丁脚本**（独立 `.py` 文件，`python _patch_xxx.py` 跑）：

```python
s = io.open(PATH, encoding="utf-8").read()
i0 = s.find("COLLAR_A0")           # 结构锚点，不用行号
i1 = s.find("SKIRT_CY = 0.006")
if s[i0:i1] != NEW_BLOCK:          # 幂等：已是目标内容就不写
    s = s[:i0] + NEW_BLOCK + s[i1:]
    io.open(PATH, "w", encoding="utf-8", newline="\n").write(s)
```

3. 写完立刻 `python -m py_compile` + `grep` 关键标记（函数名、常量值），
   确认落盘成功；
4. 收尾再核一次三个文件的时间戳与关键标记 —— 并发写入者在收尾前可能又覆盖一次；
5. **幂等**很关键：脚本重复执行不会产生副作用，被覆盖后可以再跑一次追平。

锚点用**内容**不用行号；若锚点匹配失败，先 `grep -A` 看当前实际内容再改脚本，
不要改成模糊匹配（模糊匹配会把旧实现和新实现缝在一起，语法能过但逻辑错乱）。

## 五、验收数字要带「口径 + 时点」

同一项在收口报告里必须成对出现：`实测值 + 基准/口径`。

- 凸出：`visible=+3.3mm`（相对 solidify 后袖筒外表面 48.34mm），
  同时附 `旧环层口径=+4.6mm`；
- V 深：`后领顶 1.3434 − 前领顶 1.3250 = 18.5mm`，
  并注明「未到理想 24mm，再降 6mm 会撞衬衫 V 底」；
- 峰谷差：`amp22=13.0 / amp44=3.2 → peak +16.2 / trough −9.7 / diff 25.9mm`，
  用 DFT 的 22 次分量，不用全局 max−min。

只在报告里写一个数、不写它是相对什么量的，下游一定会用它做错误决策。
