# 参数搜索：软目标量纲、默认值来源与护栏约束

本文件是 `param-search-halton-coordinate-descent.md` 的补充，专记 2026-11-01 几何段**实跑**（101 次评估、score 20.24→1.36）暴露的、容易让搜索「看起来跑了但没优化到该优化的东西」的四个坑。

## 1. 软目标必须先归一化，否则退化成单维搜索

任务给的公式是 `soft = Σ max(0, net − 8mm)`（单位**米**）+ `max(0, 0.6 − min_ratio)^2 × 4000`。

实测后果：裙腰项量级 **0.016 分**，屈指项 **20 分** → 裙腰两维（`skirt_margin`、`skirt_inner_mode`）的敏感性只有 **0.017 分**，搜索实际上只在优化屈指项，裙腰维度形同未搜。

规则：每个软目标项先除以自己的「可接受上限」或量纲基准，映射到 0~1 再加权；不要让不同单位的惩罚项直接相加。

## 2. 搜索空间的 `default` 必须从现网代码实测，不能照抄任务示例

任务示例写 `joint_blend_mm ∈ [3, 9]`、默认 5.0；实测代码里该值是 **1.5mm**（反距离 eps），默认点落在搜索盒**外**，导致 baseline 与 best 不是从同一点出发。

做法：先 `grep` 实际常量并打印 `[space] key=default`，逐项与盒的比较；越界就把区间改成包住默认值（本轮改为 `[1.0, 4.0]`）。所有 default 都要能指到 `文件:行`。

## 3. 硬约束护栏要覆盖「上一阶段已达标、但会被顺带破坏」的邻接指标

第一版只写了 5 条硬约束（裙腰 net、权重和、腕部台阶、手臂骨主导、串权）。结果最优解把裙腰收紧，**walk 姿势下有 2 个顶点越出裙面 4.11mm**（baseline 是 0 个 / 0mm）——这是真退化，但不在约束集里，搜索照选不误。

补第 6 条「walk 腿/臀越出裙面 ≤5 个且 ≤2mm」重跑后才得到可用解。

规则：
- 把上一阶段**所有 PASS 的指标**都列成硬约束，哪怕它「不是本次要优化的」。
- 双向指标（过紧/过松）必须两侧都设阈，否则搜到边界一侧就不动了。
- 约束数量增加会压缩可行域，宁可多一条护栏也不要让最优解在别的指标上退化。

## 4. 报告必须含敏感性分析与死区声明

- **敏感性**：把该维固定在默认值 vs 最优值，score 差多少。差值小于噪声（本轮裙腰 0.017）就明写「该维不敏感、未真正搜动」。
- **死区**：屈指 min 只从 0.5289 到 0.5817（阈 0.6），混合指数 p 6→2.4、平滑 3→12 都压不动 → 报「属掌根/近节 1.53mm 短边的拓扑压缩，需改 `assign_groups` 算法而非调参」，并写清扫过的区间。不要再要求同一组参数解决它。
- 某维最优值 = 默认值时写「已局部最优」，不要编造提升百分比。

## 5. 两段搜索共享 `best.json` 时必须读-改-写

几何段与像素段共用一个 `opt/best.json`。像素段写回前必须：
1. 读出原有顶层 `best_params`（几何 5 维）；
2. 原样保留，只新增 `pixel` 子段；
3. `lib/optio.param()` 的查找顺序为 `pixel.best_params` → 顶层 `best_params` → default；
4. 写完跑一次几何段探针，证明几何参数没被覆盖。

覆盖式写入会让「第二段把第一段的成果抹掉」，且现象是几何指标悄悄回到手调值。

## 6. 冒烟、预算与可复现

- **先 `--n 2`（或 4）冒烟**确认单次评估能跑通、指标合理，再跑全量；不要一上来跑 32 点。
- 预算参考：几何段 101 次 ≈ **488 秒**（单次中位 4.28s）；像素段每次含渲染 6~8s，预算 ≤24 次。
- 固定 seed（20261101），Halton 数值本身决定性，seed 只影响跳跃起点与维度乱序 → 换机器也能复现同一组采样。
- 每次评估都要 `read_factory_settings(use_empty=True)` 重建，禁止状态复用（否则上一次的材质/权重会污染下一次）。

## 7. 回滚与行为不变性

- `opt/best.json` 缺失时，构建结果必须与手调默认**逐位一致**（本轮 `b_probe` 97 行数字 0 处差异，仅多出新增日志字段）。
- 参数注入统一走 `lib/optio.param(key, default)`，`default` = 现网手调值；不要让各模块直接读 JSON，否则回滚路径不可控。
- 回滚方法要写进报告：删 `best.json` / 手改单维 / 改回枚举值。
